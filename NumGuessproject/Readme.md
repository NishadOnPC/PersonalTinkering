# Number Guessing Game

A simple command-line game written in C where you try to guess a random number.

## 🎯 Goals
* Get comfortable writing basic C code.
* Practice turning logic into working programs.
* Get comfortable writing Linux based programs in terminal/VSCode.

## 🧠 Skills Learned
* **Loops:** Using a `do-while` loop to keep the game running until you guess right.
* **Variables:** Using incrementation (`++`) to track the number of attempts.
